# Changelog

## 1.5.0

### New
- **Slay monsters task.** Track kills of a single monster or a whole Adventurer's Guild goal, e.g. "kill 1000 slimes". Thanks Celize for the idea!
- **Quest Journal integration.** Your tasks show up in Quest Journal when both mods are installed. Contributed by @Rafia-Bee in #1.
- **Overlay text size.** Each overlay has its own text size (60–100%), set on the Overlays page. Thanks MistressOfUniverses for the suggestion!
- **Recolor support.** The journal's textures can now be edited with Content Patcher, so recolors survive mod updates. Replacing the image files still works too. Thanks RoseProse for asking!

### Fixed
- Farmhands' tasks and overlay settings are now saved in multiplayer. Thanks Lunluna for the report!
- Build and house upgrade tasks now count correctly for farmhands.
- The Tasks, Notes and Overlays tabs and the title banner now follow the game's "Menu Background" option. Thanks SilverJD for the report!
- An empty notes overlay no longer shows up as a black box on the HUD. Thanks Zombiekilla05 for the report!
- Item tasks no longer stop counting after a quickload with QuickSave.
- Overlays no longer lose their position and size when the game window gets smaller.
- Notes are saved automatically again while the journal stays open.
- Upgrade tool tasks no longer mistake other tools for the trash can.

### Changed
- All task type buttons now fit in one row.
- Requires SMAPI 4.1.0 or later (Stardew Valley 1.6.9 or later, as before).

Earlier versions: see the Changelogs tab on Nexus Mods.
